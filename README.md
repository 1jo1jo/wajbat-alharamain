 Wajbat Alharamain Website | موقع وجبة الحرمين

 About the Project | عن المشروع

Wajbat Alharamain is a web platform developed to facilitate meal requests and donations for Hajj and Umrah visitors. It connects meal providers with beneficiaries through an easy-to-use digital platform.

وجبة الحرمين هو موقع إلكتروني يهدف إلى تسهيل طلب الوجبات والتبرع بها لضيوف الرحمن من حجاج ومعتمري بيت الله الحرام، من خلال منصة رقمية تربط المطاعم بالمستفيدين.

 Technologies Used | التقنيات المستخدمة

- HTML
- CSS
- JavaScript
- REST API

 Main Features | المميزات الرئيسية

- User Registration and Login | تسجيل الدخول وإنشاء الحساب.
- Browse Meals | استعراض الوجبات.
- Meal Donations | التبرع بالوجبات.
- Order Management | إدارة الطلبات.
- Payment Process | عملية الدفع.

 Backend | الواجهة الخلفية

The website is connected to a backend developed using Spring Boot and a MySQL database.
